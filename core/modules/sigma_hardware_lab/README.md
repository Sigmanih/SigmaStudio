# Hardware Lab & VRAM Telemetry — Sigma Studio Module

Modulo open-source di monitoraggio e controllo hardware per **Sigma Studio**.

## Funzionalità
- ⚡ Telemetria live VRAM GPU (allocata, riservata, libera, temperatura)
- 📊 Grafici in tempo reale di utilizzo memoria e carico GPU/CPU
- 🧹 Gestione e pulizia cache VRAM / riavvio runtime Ollama
- 🛑 Monitor processi CUDA e terminazione processi zombie
- 🤖 Tool MCP per ispezione telemetrica da parte degli agenti AI

## Installazione
Dall'**Hub Moduli & Estensioni** di Sigma Studio → Installa "Hardware Lab & VRAM Telemetry"
